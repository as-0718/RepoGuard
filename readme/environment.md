# 环境依赖说明

## 一、运行时要求

| 运行时 | 版本要求 | 说明 |
|---|---|---|
| Python | ≥ 3.10 | 后端服务、规则引擎、巡检与 CLI；开发实测 3.11.15 |
| Node.js | ≥ 22.12 | 仅前端看板构建与开发模式需要；实测 v24.19.0 / npm 11.17.0 |

> 规则引擎、全仓巡检、README 目录生成与命令行工具仅使用 Python 标准库，不依赖任何第三方包。

## 二、后端直接依赖（`backend/requirements.txt`）

| 包 | 版本 | 用途 | 许可证 |
|---|---|---|---|
| fastapi | 0.115.6 | Web API 框架 | MIT |
| uvicorn | 0.34.0 | ASGI 服务器 | BSD-3-Clause |
| httpx | 0.28.1 | 仅供 Web API 单元测试的 TestClient 使用 | BSD-3-Clause |

其余 fastapi 传递依赖（如 starlette、pydantic）随 fastapi 安装，不在本项目直接声明。

## 三、前端直接依赖（`frontend/package.json`）

| 包 | 版本 | 用途 | 许可证 |
|---|---|---|---|
| vue | 3.5.45 | 视图框架 | MIT |
| vue-router | 4.6.4 | 前端路由 | MIT |
| echarts | 6.1.0 | 图表可视化 | Apache-2.0 |
| vite | 8.3.6 | 前端构建与开发服务器 | MIT |
| @vitejs/plugin-vue | 6.0.10 | Vue 单文件组件支持插件 | MIT |

## 四、测试基线

| 阶段 | 测试数 | 结果 |
|---|---|---|
| 阶段 4（Webhook + OpenAPI） | 310 | 2 条既有符号链接失败、1 条跳过 |
| 阶段 5（看板 + 部署） | 377 | 2 条既有符号链接失败、2 条跳过 |
| 最终回归 | 438 | 全部通过，4 条跳过 |

## 五、不依赖的外部服务

- 无数据库、无缓存中间件、无消息队列；
- 看板缓存位于 API 进程内存（TTL 60 秒、LRU 容量 8），只支持单实例；
- 工具只读离线运行，不联网请求外链、不执行被扫描代码。
