RepoGuard 命令清单（Windows PowerShell）
=====================================================

【必读：一些地方要按自己电脑改】

1. 项目路径
   下面命令里的 C:\Users\anshuai\Desktop\RepoGuard
   → 替换成你电脑上 RepoGuard 项目所在的文件夹路径。

2. Python 解释器
   先在终端敲：python --version
   - 如果能打印出 Python 3.11.x 版本号：下面命令里的 “& $py” 直接换成 “python”，
     可以跳过第 2 步。
   - 如果回车后没有任何输出（这是微软商店占位别名失效）：
     把第 2 步 $py 后面的路径，换成你电脑上可用的 Python 解释器完整路径。

3. 端口 8000 / 5173 一般不用改；被占用时再换。

提示：$py 这个变量只在当前这个终端窗口有效；另开新窗口要重新执行第 2 步。


=====================================================
一、终端命令（在 backend 目录跑，录屏主体）
=====================================================

【第 1 步】进入后端目录
用途：三条命令都依赖 backend 目录下的 app 代码，必须先进这里。
命令：

cd C:\Users\anshuai\Desktop\RepoGuard\backend


【第 2 步】指定可用的 Python 解释器（裸 python 失效时才需要）
用途：定义变量 $py 指向能用的解释器，同一窗口后续命令直接复用。
命令：

$py = "C:\Users\anshuai\AppData\Roaming\uv\python\cpython-3.11.15-windows-x86_64-none\python.exe"

# 验证解释器正常：应打印 Python 3.11.15
& $py --version


【第 3 步】全仓健康巡检
用途：对内置样本仓库 demo-repo 做全仓扫描，按“高风险 / 建议”分级，
      覆盖命名、代码、链接、敏感信息四类问题。
命令：

& $py -m app.health.cli --repo ../demo-repo --format text

# 预期结果：8 个文件，21 个问题（高风险 11、建议 10）；僵尸候选 0；无法判定 8。


【第 4 步】规则引擎：按变更清单做四类规则检查
用途：读取一份变更清单（新增/修改/删除），逐条套用规则，
      输出“必须修改 / 优化建议”两级结果。
命令：

& $py -m app.core.rules.engine --manifest tests/fixtures/sample_changes.txt --repo ../demo-repo --format text

# 预期结果：21 个问题（必须修改 11、优化建议 10）。


【第 5 步】README 目录生成
用途：扫描仓库里的文档和 Demo 工程，自动生成文档索引与 Demo 分区，
      并和现有 README 做差异对比。
命令：

& $py -m app.readme.cli --repo ../demo-repo

# 预期结果：文档 3 个、疑似 Demo 工程 2 个。


=====================================================
二、启动看板（浏览器演示，需要另开窗口）
=====================================================

【后端服务】仍在 backend 目录，这个窗口启动后不要关
用途：提供看板数据接口（端口 8000）。
命令：

& $py -m uvicorn app.api.app:app --host 127.0.0.1 --port 8000


【前端看板】另开一个 PowerShell 窗口
用途：启动可视化看板页面（端口 5173）。
命令：

cd C:\Users\anshuai\Desktop\RepoGuard\frontend
npm run dev

# 若 npm 报缺少依赖：先在 frontend 目录跑 npm install（或 npm ci），需要联网。


【浏览器打开以下页面】

概览页：   http://127.0.0.1:5173/overview
问题列表： http://127.0.0.1:5173/issues
仓库结构： http://127.0.0.1:5173/structure


=====================================================
三、常见问题对照
=====================================================

- No module named app：没有在 backend 目录，重新执行第 1 步 cd。
- 命令回车后没有任何输出：裸 python 是商店占位别名，改用第 2 步的全路径解释器。
- npm 报错缺少包：先在 frontend 目录执行 npm install 装依赖，再 npm run dev。
- 前端页面连不上数据：确认后端窗口还开着、8000 端口没被别的程序占用。
- 换了电脑后路径报红：把命令里的项目路径、解释器路径按【录屏前必读】第 1、2 条替换。
